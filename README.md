# Belbin チームロール分類アプリ（αβγスコアベース）

議論中の発言をリアルタイムで分析し、各発言者の [Belbinチームロール](https://en.wikipedia.org/wiki/Team_Role_Inventories) を推定するStreamlitアプリです。

## 特徴

**推論モデルを使わずにスコアのみでロールを判定します。**

発言の内容を以下の3つのスコアに変換し、その組み合わせでロールを決定します。推論モデル（fine-tuned分類器）は使用しないため、軽量に動作します。

## スコアの定義

| スコア | 意味 | 計算方法 |
|--------|------|----------|
| **α（発言量比率）** | その話者が全体の会話をどれだけ占めているか | 話者の累積文字数 ÷ 全参加者の累積文字数 |
| **β（新規提案率）** | どれだけ新しい内容を持ち込んでいるか | BERTコサイン類似度 + TF-IDFで過去発言との類似度を測り、低類似度（新規）な発言の割合 |
| **γ（調整発言比率）** | どれだけ場を調整・まとめる発言をしているか | 調整キーワード（「まとめ」「確認」「どうですか」等）を含む発言の重みつき比率 |

## ロール判定ロジック

3系統のロールをそれぞれ独立に判定します。

### 思考系
| ロール | 主なシグナル |
|--------|-------------|
| プラント | β高め・一人称あり・新規性の高い発言 |
| モニター評価者 | γ高め・過去発言との重複あり |
| スペシャリスト | α高め・専門語・長文 |

### 対人関係系
| ロール | 主なシグナル |
|--------|-------------|
| リソース探究者 | β高め |
| コーディネーター | α高め・他者への言及あり |
| チームワーカー | γ高め |

### 行動系
| ロール | 主なシグナル |
|--------|-------------|
| 実行者 | β高め・一人称あり |
| 完遂者 | α高め・日付・締切ワードあり |
| シェイパー | γ高め・呼びかけ（〜さん等）あり |

## ファイル構成

```
プログラム/
├── NewApp.py                  # Streamlitアプリ本体
├── mecanism.py                # αβγスコア計算・ロール判定ロジック
└── 2025春/
    ├── aplication.py          # 旧バージョン（推論モデルあり・現在停止中）
    ├── train_all_classifiers.py
    ├── generate_label_maps.py
    ├── labo.py
    ├── output_belbin_multidim.csv
    └── fine_tuned_belbin/     # 学習済みSentenceTransformerモデル（モデル重みは除外）
```

## 使い方

```bash
pip install streamlit sentence-transformers scikit-learn
streamlit run プログラム/NewApp.py
```

発言を以下の形式で入力します：

```
田中: このプロジェクトの方針を明確にする必要があります
鈴木: なるほど、皆さんどう思いますか？
佐藤: 私はAI活用を提案します
```

各発言に対して思考系・対人関係系・行動系のロールが表示されます。

## 使用モデル

新規性判定（β計算）にのみBERT埋め込みを使用しています。

- [cl-tohoku/bert-base-japanese-v2](https://huggingface.co/cl-tohoku/bert-base-japanese-v2)
