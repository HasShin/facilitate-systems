# 議論ファシリテーション支援ツール

議論中の発言をリアルタイムで分析し、各発言者のチームロールを推定するStreamlitアプリです。

---

## 現在のアプローチ（2026/）

**推論モデルを使わず、3つのスコアだけでロールを判定します。**

発言ごとに α・β・γ を算出し、その大小関係とキーワードでロールを決定します。

### スコアの定義

| スコア | 意味 | 計算方法 |
|--------|------|----------|
| **α（発言量比率）** | 会話全体に占める発言の割合 | 話者の累積文字数 ÷ 全参加者の累積文字数 |
| **β（新規提案率）** | 新しい内容を持ち込んでいる割合 | BERTコサイン類似度 + TF-IDFで過去発言との類似度を測り、低類似度（新規）な発言の割合 |
| **γ（調整発言比率）** | 場を調整・まとめる発言の割合 | 調整キーワード（「まとめ」「確認」「どうですか」等）を含む発言の重みつき比率 |

### ロール判定ロジック

3系統のロールをそれぞれ独立に判定します。

**思考系**
| ロール | 主なシグナル |
|--------|-------------|
| プラント | β高め・一人称あり・新規性の高い発言 |
| モニター評価者 | γ高め・過去発言との重複あり |
| スペシャリスト | α高め・専門語・長文 |

**対人関係系**
| ロール | 主なシグナル |
|--------|-------------|
| リソース探究者 | β高め |
| コーディネーター | α高め・他者への言及あり |
| チームワーカー | γ高め |

**行動系**
| ロール | 主なシグナル |
|--------|-------------|
| 実行者 | β高め・一人称あり |
| 完遂者 | α高め・日付・締切ワードあり |
| シェイパー | γ高め・呼びかけ（〜さん等）あり |

### 使い方

```bash
pip install streamlit sentence-transformers scikit-learn
streamlit run プログラム/2026/NewApp.py
```

発言を以下の形式で入力します：

```
田中: このプロジェクトの方針を明確にする必要があります
鈴木: なるほど、皆さんどう思いますか？
佐藤: 私はAI活用を提案します
```

各発言に対して思考系・対人関係系・行動系のロールが表示されます。

> β計算（新規性判定）のみ [cl-tohoku/bert-base-japanese-v2](https://huggingface.co/cl-tohoku/bert-base-japanese-v2) の埋め込みを使用しています。

## 旧アプローチ（2025/）

Fine-tuningしたSentenceTransformerモデルとsklearn分類器を組み合わせ、発言から直接ロールを推論する方式を試みました。現在は推論を停止し（`ENABLE_MODEL_INFERENCE = False`）、スコアベースの現行方式に移行しています。

### パイプライン

```
ラベル済みCSV → labo.py（データ統合）
             → generate_label_maps.py（ラベルID変換）
             → SentenceTransformerのFine-tuning（別途実施）
             → train_all_classifiers.py（分類器の学習）
             → aplication.py（Streamlitアプリで推論）
```

### 各ファイルの役割

| ファイル | 役割 |
|----------|------|
| `labo.py` | 複数のラベル済みCSVを結合して学習データを作成 |
| `generate_label_maps.py` | ロールラベルをID変換するマップを生成し `label_maps.pkl` として保存 |
| `train_all_classifiers.py` | Fine-tuned Sentence-BERTで発言をベクトル化し、思考系・対人関係系・行動系それぞれにLogistic Regression分類器を学習 |
| `output_belbin_multidim.csv` | 学習に使用したラベル済みデータ（発言 + 3系統のロールラベル） |
| `aplication.py` | 上記で学習したモデル・分類器を使ってリアルタイム推論するStreamlitアプリ（現在停止中） |
| `fine_tuned_belbin/` | Fine-tuningしたSentenceTransformerのモデル設定ファイル（モデル重みは容量超過のため除外） |
