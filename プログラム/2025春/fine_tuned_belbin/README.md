# SentenceTransformer based on sonoisa/sentence-bert-base-ja-mean-tokens

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sonoisa/sentence-bert-base-ja-mean-tokens](https://huggingface.co/sonoisa/sentence-bert-base-ja-mean-tokens). It maps sentences & paragraphs to a 768-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, text classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sonoisa/sentence-bert-base-ja-mean-tokens](https://huggingface.co/sonoisa/sentence-bert-base-ja-mean-tokens) <!-- at revision 332c1193c5a913916c0702f2769ca7f55c8addaf -->
- **Maximum Sequence Length:** 512 tokens
- **Output Dimensionality:** 768 dimensions
- **Similarity Function:** Cosine Similarity

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```

Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    "Utterance(participant='G3M', tokens=[Token(word='あれは無いよねとか', pos=None, mor=None, gra=None), Token(word='.', pos=None, mor=None, gra=None)], time_marks=(935758, 939162), tiers={'G3M': 'あれは無いよねとか . \\x15935758_939162\\x15', '%ort': 'are wa nai yo ne: toka .'})",
    "Utterance(participant='G3M', tokens=[Token(word='あれは無いよねとか', pos=None, mor=None, gra=None), Token(word='.', pos=None, mor=None, gra=None)], time_marks=(935758, 939162), tiers={'G3M': 'あれは無いよねとか . \\x15935758_939162\\x15', '%ort': 'are wa nai yo ne: toka .'})",
    "Utterance(participant='H3M', tokens=[Token(word='絶対駄目なタイプない', pos=None, mor=None, gra=None), Token(word=',', pos=None, mor=None, gra=None), Token(word='絶対駄目なタイプ', pos=None, mor=None, gra=None), Token(word='?', pos=None, mor=None, gra=None)], time_marks=(837731, 844107), tiers={'H3M': '絶対駄目なタイプない, 絶対駄目なタイプ ? \\x15837731_844107\\x15', '%ort': 'zettai dame na taipu nai „ zettai dame na taipu ?'})",
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 768]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[1.0000, 1.0000, 0.9011],
#         [1.0000, 1.0000, 0.9011],
#         [0.9011, 0.9011, 1.0000]])
```
